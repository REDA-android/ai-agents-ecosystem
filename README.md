# AI Agents Ecosystem

A curated collection of leading AI Agent frameworks, automation platforms, developer tools, harnesses, and learning resources organized as Git submodules.

## 📂 Included Repositories (16 Projects)

### 🧠 1. Multi-Agent Frameworks & Core Orchestration
- **[AutoGen](https://github.com/microsoft/autogen)** (`sources/autogen`): Multi-agent conversation and orchestration framework by Microsoft.
- **[Agent Framework](https://github.com/microsoft/agent-framework)** (`sources/agent-framework`): Microsoft framework ecosystem for building AI agents.
- **[LangChain](https://github.com/langchain-ai/langchain)** (`sources/langchain`): Leading framework for building LLM and agentic applications.
- **[Google ADK Python](https://github.com/google/adk-python)** (`sources/adk-python`): Google Agent Development Kit for Python.

### 🌐 2. Web, Desktop & OS Automation
- **[Browser Use](https://github.com/browser-use/browser-use)** (`sources/browser-use`): Enable AI agents to interact with websites and web apps.
- **[Goose](https://github.com/aaif-goose/goose)** (`sources/goose`): Open-source AI agent for software engineers in shell and IDE.
- **[Gemini CLI](https://github.com/google-gemini/gemini-cli)** (`sources/gemini-cli`): CLI interface and scripting tool for Google Gemini models.
- **[ECC](https://github.com/affaan-m/ECC)** (`sources/ECC`): Everything Computer Control for agentic operating system interaction.

### 🔬 3. Open Agent Models, Graphs & Benchmarks
- **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** (`sources/hermes-agent`): Agent architecture and tools for Nous Hermes models.
- **[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)** (`sources/deepseek-harness`): Evaluation and benchmarking harness for DeepSeek models.
- **[Graphify](https://github.com/Graphify-Labs/graphify)** (`sources/graphify`): Knowledge-graph-powered agentic tools and reasoning.
- **[Omnigent](https://github.com/omnigent-ai/omnigent)** (`sources/omnigent`): Multi-modal omni-agent platform.
- **[Airi](https://github.com/moeru-ai/airi)** (`sources/airi`): Interactive companion and virtual character agent.

### 📚 4. Curated Lists & Learning Resources
- **[500 AI Agents Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)** (`sources/500-AI-Agents-Projects`): 500+ curated AI Agent implementations and tutorials.
- **[GenAI Agents](https://github.com/NirDiamant/GenAI_Agents)** (`sources/GenAI_Agents`): Comprehensive tutorials and architecture patterns.
- **[AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners)** (`sources/ai-agents-for-beginners`): Beginner curriculum by Microsoft.

## 🚀 Cloning & Initializing

To clone this repository along with all submodules:

```bash
git clone --recurse-submodules https://github.com/REDA-android/ai-agents-ecosystem.git
```

If you have already cloned the repository without submodules:

```bash
git submodule update --init --recursive
```
