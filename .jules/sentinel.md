## 2023-10-24 - [Command Injection via Unvalidated Code Execution]
**Vulnerability:** The `/api/code/execute` endpoint took raw code and immediately executed it using `subprocess.run` via a temporary file. This bypassed the security guardrails implemented elsewhere in the application, leading to arbitrary code execution (ACE) and command injection vulnerabilities.
**Learning:** Adding new execution endpoints without incorporating existing centralized security mechanisms (like `guardrail.evaluate_command`) inherently introduces high severity vulnerabilities. It's easy for new features to sidestep defense-in-depth measures if security policies are not treated as a mandatory prerequisite for *any* shell/OS invocation.
**Prevention:** All inputs destined for code execution, shell commands, or OS-level operations must be validated against `SafetyGuardrail.evaluate_command` *before* being processed, regardless of whether they are run directly or via intermediate temporary files.
